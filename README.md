This project will include a user interface developed with Vue.js, a REST-style Web API,
and a database where the information is stored. <br>
The user interface will show the list items to users and allow users to manipulate the list. <br>
The actions performed by users should send to the Web API, which will perform CRUD operations in a SQLite database and return the results via HTTP response messages to the client side.<br>

This project is the first phase test.<br>
The website is use vue to design a web application.
